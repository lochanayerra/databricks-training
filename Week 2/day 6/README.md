# MySQL String Functions Practice

This project contains practice examples for String Functions in MySQL.

The assignment demonstrates commonly used string manipulation functions with real-time employee data.


# Files Included

## 1. data_creation.sql
Contains:
- Table creation
- Sample employee data insertion

## 2. queries.sql
Contains:
- String function queries
- Data cleaning operations
- String extraction examples

## 3. outputs.txt
Contains:
- Expected outputs for all queries

## 4. README.md
Project documentation

# Functions Used

| Function | Purpose |
|----------|----------|
| LENGTH() | Count total bytes |
| CHAR_LENGTH() | Count characters |
| UPPER() | Convert to uppercase |
| LOWER() | Convert to lowercase |
| TRIM() | Remove spaces |
| CONCAT() | Combine strings |
| SUBSTRING() | Extract substring |
| LEFT() | Left-side extraction |
| RIGHT() | Right-side extraction |
| INSTR() | Find substring position |
| LOCATE() | Locate character |
| REPLACE() | Replace text |
| REVERSE() | Reverse string |
| LPAD() | Left padding |
| RPAD() | Right padding |
| IFNULL() | Replace NULL |
| COALESCE() | First non-null value |
