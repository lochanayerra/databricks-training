# MySQL REGEX Basic Assignment

This project contains REGEX practice queries in MySQL using `REGEXP_SUBSTR()`.

The assignment focuses on extracting patterns such as:

- Digits
- Alphabets
- Email username/domain
- Country codes
- Prefix/suffix values
- Text between symbols
- Continuous numeric/alphabetic sequences

---

# Files Included

## 1. data_creation.sql
Contains:
- Table creation
- Sample data insertion

## 2. queries.sql
Contains:
- 20 REGEX extraction queries
- Usage of REGEXP_SUBSTR()
- REPLACE() with REGEX

## 3. outputs.txt
Contains:
- Expected outputs for all queries

---

# Concepts Covered

## REGEX Basics

| Symbol | Meaning |
|--------|---------|
| ^ | Start of string |
| $ | End of string |
| + | One or more continuous characters |
| {} | Exact number of characters |
| [] | Character range |
| \ | Escape special character |
