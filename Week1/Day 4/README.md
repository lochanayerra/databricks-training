# Day 4 - SQL Window Functions and CTEs

## Overview
This project contains practice queries on SQL Window Functions and Common Table Expressions (CTEs) using MySQL 8+.

The assignment covers:
- ROW_NUMBER()
- RANK()
- DENSE_RANK()
- NTILE()
- LAG()
- LEAD()
- Running Totals
- Moving Averages
- PARTITION BY
- Recursive CTEs
- Employee Hierarchy
- Ranking Queries
- Aggregate Window Functions

---

## Tables Used

### Employees
Contains employee details such as:
- employee_id
- employee_name
- department
- manager_id
- salary
- hire_date

### Customers
Contains customer information:
- customer_id
- customer_name
- city

### Orders
Contains order details:
- order_id
- customer_id
- employee_id
- order_date
- total_amount
